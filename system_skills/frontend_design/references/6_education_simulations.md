# Education & Interactive Simulations Design Guidelines

This reference covers interactive educational sandboxes, conceptual learning simulations, scientific process visualizers, math interactive models, and rubric-based assessment interfaces.

## 1. Two-Zone Sandbox Layout
- Left / Top: Interactive Stage (60%–70% viewport). Large visual canvas displaying system in motion.
- Right / Bottom: Control & Concept Deck. Parameter sliders, step-by-step playback controls (Play, Pause, Step, Reset), real-time annotations.

## 2. Progressive Disclosure & Guided Learning
- Progressive stages (e.g. Stage 1: Resting State → Stage 2: Elevated Activity).
- Immediate visual feedback on parameter adjustment.
- Directional pulse flows for signals, fluids, and molecular transfer.

## 3. Educational Color & Typography
- Tabular figures for math parameters.
- Formulas in clean italic math notation.
- Dual-coded state indicators: never hue alone.
