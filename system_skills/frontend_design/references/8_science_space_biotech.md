# Science, Space & Biotech Design Reference

This guide covers design aesthetics, visual hierarchy, layout architecture, and precision data presentation for scientific dashboards, aerospace telemetry, laboratory instrumentation, and physical simulations.

## 1. Aesthetic DNA & Visual Tone
- Precision, calibration, and empirical authority.
- 60% clinical lab white or deep space obsidian background.
- 30% structural flat slate panels with 1px hairline borders.
- 10% single calibrated phosphor accent (cyan, amber, cobalt).

## 2. Precision Typographic System
- Interface labels in clean geometric sans.
- Measurements, timestamps, coordinates in dedicated monospace tabular figures.
- Explicit scientific unit notation (μm, nm, GHz, mol/L, °C, Δv).
- Uniform decimal significant figures across data columns.

## 3. Asymmetric Split Console Layout
- Top Telemetry Ribbon (36px–44px): System status, elapsed time, preset selector.
- Left Parameter Column (300px–380px): Collapsible parameter accordions, fine-grained sliders.
- Main Viewport Stage: High-fidelity simulation canvas with HUD crosshair probes.
- Bottom Time-Series Tray: Multi-channel wave graphs and batch comparison tables.
