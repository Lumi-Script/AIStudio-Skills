# Google Sheets API

## Scopes
- https://www.googleapis.com/auth/spreadsheets — View and edit spreadsheets.
- https://www.googleapis.com/auth/spreadsheets.readonly — View spreadsheets.

## Key Concepts
- Spreadsheets: Collections of individual sheet tabs.
- Values: Cell ranges addressed in A1 notation (e.g. Sheet1!A1:D10).
