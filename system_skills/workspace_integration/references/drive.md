# Google Drive API

## Scopes
- https://www.googleapis.com/auth/drive — Full drive file management.
- https://www.googleapis.com/auth/drive.file — Specific app-created files only.
- https://www.googleapis.com/auth/drive.readonly — Read-only file access.

## Key Concepts
- Files & Folders: File metadata and content.
- Permissions: Access control lists.
