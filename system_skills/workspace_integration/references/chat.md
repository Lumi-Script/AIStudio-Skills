# Google Chat API

## Scopes
- https://www.googleapis.com/auth/chat.spaces — View and manage spaces.
- https://www.googleapis.com/auth/chat.messages — View, create, and edit messages.
- https://www.googleapis.com/auth/chat.memberships — Manage space memberships.

## Key Concepts
- Spaces: Rooms or direct conversations.
- Messages: Rich cards and plain text communications.
