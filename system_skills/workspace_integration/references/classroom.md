# Google Classroom API

## Scopes
- https://www.googleapis.com/auth/classroom.courses — View and manage courses.
- https://www.googleapis.com/auth/classroom.coursework.students — Manage student assignments.
- https://www.googleapis.com/auth/classroom.rosters — Access student rosters.

## Key Concepts
- Courses: Classroom subjects and sections.
- CourseWork: Assignments, questions, and learning materials.
